# 세대별 뉴스 소비 경로 차이 — 주제 설명과 데이터분석 계획

202406228 김경현 · 데이터리터러시의이해 중간 대체 과제

[계획서 HTML 열기](news-analysis-plan.html)

사용자가 작성한 주제 설명과 계획 문단만 6장으로 정리했습니다.

1. 표지
2. 주제 선정 배경
3. 일상 경험과 분석하고 싶은 질문
4. AI 데이터 정리·연령대별 비교·공식 통계표 대조 계획
5. 수업 도구와 모션을 활용한 시각화 계획
6. 부족한 정보를 보완하기 위한 추가 자료 수집 계획

BMW M의 검정·흰색, 직선형 구획, 삼색 포인트를 유지했습니다. 참고자료의 분석 내용, 수치, 변수·문항 정의, 그래프 예시를 넣지 않았습니다. Anime.js는 본문 등장 모션에 사용했습니다.

이미지·스크립트가 내장된 단일 파일로, Chrome에서 인터넷 없이 열 수 있습니다. ←/→·Space·Home/End 이동, M 모션 켜기/끄기, R 재생, F 전체 화면을 지원합니다.

- `src/`: 편집용 HTML·CSS·JS
- `assets/`: 표지·Anime.js 및 이전 제작 단계의 보존 에셋
- `analysis/`: 이전 제작 단계의 보존 코드(현재 6장 덱에서 사용하지 않음)
- `docs/`: 디자인·원고·수정 기록
- `dist/index.html`: 단일 HTML의 동일 복사본

재생성: `python3 news-analysis-plan/build.py`

이 폴더는 중간 대체 과제 계획서입니다. 기존 뉴스 분석 결과물과 OTT 과제1은 별도 폴더에 보관합니다.
