# 수정 범위와 근거

현재 계획서는 사용자가 직접 작성한 5개 문단과 표지로 구성한 6장 덱이다.
원문을 슬라이드에 맞게 분리하고 제목을 붙였으며 의미를 유지했다.

- 참고자료의 조사 수치·변수·문항 설명·분석 방법의 세부 확장·빈 그래프 예시·절차 영상을 제거했다.
- 주제 선정 배경, 일상 경험, AI 정리·연령별 경로와 매체별 이용률 비교, 공식 통계표 대조, HTML 결과물, 시각화·모션, 추가 자료의 비교 가능성만 유지했다.
- BMW M 디자인 유지. 표지는 기존 Google Flow AI 생성 에셋이고 표지에서 고지한다.
- 사용자가 업로드를 요청하기 전에는 GitHub 업로드와 웹 배포를 진행하지 않는다.

검수: 현재 6장 전체를 Chrome에서 확인했고, 본문 줄바꿈·여백을 점검했다. 이전/다음·Home/End 이동, 내장 에셋과 JavaScript 문법도 확인했다.

2026-10-18 추가 수정: 진행바의 10장 고정 분모를 실제 슬라이드 수(6장)로 교체하고, 페이지 번호를 1/6 형식으로 통일했다. 마지막 슬라이드 수업명은 한글로 바꿨다. 4~6장 제목과 본문은 반복적인 다짐 대신 분석 내용·시각화 구상·자료 보완 조건을 설명하는 문장으로 다듬었다. 6개 진행률과 마지막 100%, 번호 형식, 한글 수업명은 DOM 검증을 통과했다.

사용자 의도 반영: 모션의 목적은 발표의 지루함을 줄이는 것으로 수정했다. 마지막 장의 ‘자료를 고르는 기준’ 항목은 삭제하고, 원자료로 확인하기 어려운 정보를 추가 자료로 보완한다는 계획만 남겼다.
