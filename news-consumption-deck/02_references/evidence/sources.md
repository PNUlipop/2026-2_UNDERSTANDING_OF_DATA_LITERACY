## SRC-001 — 2025 언론수용자 조사

- 발행: 한국언론진흥재단, 2025.12.31.
- 자료 위치: `00_inbox/fileidDownLoad/` (사용자 제공 원본 5개 보존)
- 파일: 설문지 겸 코드북 PDF, 최종데이터 XLSX·SAV, 통계표 PDF, 보고서 PDF
- 조사: 전국 만 19세 이상 6,000명, 2025.7.8.~9.2., 태블릿 대면면접
- 분석: 공개 SAV 6,000행. DQ3로 19–29 / 30–39 / 40–49 / 50–59 / 60–69 / 70세 이상 분류. WT 가중치 적용.
- 주 이용 경로: Q84 단일응답, 비이용 코드 9998 포함
- 주간 뉴스 이용: Q13=1, Q31_1=1 또는 Q31_2=2, Q46=1, Q53=1, Q61=1, Q73=1
- 주간 이용 문항은 경로 간 중복 허용. 두 동영상 문항의 중복은 동일 응답자의 응답 조합으로 계산.
- 보고서 참조: p.48 조사 설계, p.70 표 4-2 주 이용 경로, p.96 포털 뉴스, p.110 SNS 뉴스, p.116 온라인 동영상 뉴스, p.122 숏폼 뉴스.
- 검증: 연령별 TV·포털 주 이용률 12개 값과 전체 주요 비율을 보고서 표 4-2에 대조, 소수점 첫째 자리 일치.
- 실제 n: 828 / 869 / 1,038 / 1,189 / 1,098 / 978. 보고서 표의 사례수는 가중 사례수로 다름.
- 재현 코드: `03_content/analysis/analyze.py`
